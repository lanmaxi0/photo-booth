# 네컷의 온도 📸

사진 4장을 필터, 프레임 문구, 스티커로 꾸미고 하나의 PNG 이미지로 저장하는 인생4컷 웹앱입니다. 크림색 종이 질감과 라임색 포인트, 콜라주 분위기의 화면으로 구성했습니다.

## 주요 기능

- 사진 4장 개별 업로드 및 여러 장 한 번에 업로드
- 업로드한 사진 교체
- 필터 6종: 오리지널, 소프트, 빈티지, 흑백, 핑크빛, 선명하게
- 프레임 색상 6종: 크림, 차콜, 세이지, 핑크, 블루, 라임
- 프레임 문구 입력: 최대 32자
- 기기의 오늘 날짜 표시 및 숨기기
- 스티커 8종 추가: 최대 30개
- 미리보기에서 스티커 드래그 이동, 크기 조절, 선택 삭제 및 전체 삭제
- 완성한 사진을 720 × 1940 픽셀 PNG 이미지로 다운로드
- 사진과 꾸미기 전체 초기화
- 모바일 화면에 맞춘 반응형 레이아웃

## 실행 방법

`index.html`을 최신 Chrome 또는 Edge 브라우저로 엽니다.


## 사용 방법

1. **사진 담기**: 사진 영역을 눌러 한 장씩 선택하거나, **사진 여러 장 한 번에 넣기**를 누릅니다. 여러 장을 선택하면 처음 네 장을 1번부터 차례로 배치합니다.
2. **필터 선택**: 원하는 분위기의 필터를 선택합니다. 선택한 필터는 네 장 모두에 적용됩니다.
3. **프레임 꾸미기**: 프레임 색상을 고르고 문구를 입력합니다. 날짜 표시 여부도 선택할 수 있습니다.
4. **스티커 꾸미기**: 스티커 버튼을 누르고 미리보기에서 끌어 옮깁니다. 스티커를 선택한 뒤 크기 슬라이더나 **선택 삭제**를 사용할 수 있습니다.
5. **다운로드**: 사진 네 장을 모두 넣은 뒤 **네 컷 다운로드**를 누르면 완성된 PNG 이미지를 저장합니다.

**전체 초기화**를 누르고 확인하면 사진, 문구, 필터, 프레임과 스티커가 초기화됩니다.

## 기술 구성

| 기술 | 용도 |
| --- | --- |
| HTML | 화면과 입력 요소 구성 |
| CSS | 반응형 레이아웃, 색상, 종이 질감 표현 |
| JavaScript | 사진 불러오기 및 꾸미기 동작 |
| Canvas 2D API | 사진 합성, 필터 처리, 문구·스티커 렌더링 |
| Pointer Events | 마우스 및 터치를 이용한 스티커 이동 |
| Blob / Object URL | 이미지 파일 불러오기 및 PNG 다운로드 |
| Google Fonts | 온라인 환경에서 Noto Sans KR 글꼴 불러오기 |

프레임워크, 패키지 설치, API 키가 필요하지 않습니다.

## 코드 수정 안내

`index.html` 를 코드 편집기로 열어 수정합니다.

| 수정 항목 | 찾을 위치 |
| --- | --- |
| 웹앱 제목 | `<title>` 및 `.brand` 요소 |
| 배경색·포인트 색상 | CSS의 `:root` 변수 |
| 기본 프레임 문구 | `id="caption"`의 `value`와 초기화 함수의 문구 |
| 필터 종류와 강도 | JavaScript의 `filters` 객체 |
| 프레임 색상 | 색상 코드가 들어 있는 배열 |
| 스티커 종류 | 이모지가 들어 있는 배열 |
| 이미지 합성 및 문구 배치 | `draw()` 함수 |
| 다운로드 파일명 | `a.download` 설정 |

출력 해상도를 바꾸려면 캔버스 크기뿐 아니라 `draw()`의 배치 좌표와 `point()`의 좌표 변환도 함께 수정해야 합니다.

## 사진 처리 및 개인정보

- 선택한 사진은 브라우저 안에서 처리하며 서버에 업로드하지 않습니다.
- 사진과 편집 상태를 서버나 브라우저 저장소에 보관하지 않습니다.
- 페이지를 새로고침하거나 닫으면 편집 내용이 사라집니다. 완성 후 PNG로 저장하세요.
- 온라인 환경에서는 Google Fonts에 연결해 글꼴을 불러옵니다. 오프라인에서는 기본 글꼴로 표시됩니다.

## 현재 동작 및 제한 사항

- 사진은 각 칸을 채우도록 중앙 기준으로 자동 잘립니다. 사진 위치 이동, 확대·축소, 수동 자르기 기능은 없습니다.
- 긴 사진은 일부 영역이 잘릴 수 있으므로 중요한 피사체가 중앙에 있는 사진을 사용하세요.
- 업로드 사진은 처리 부담을 줄이기 위해 긴 변이 최대 2,000픽셀이 되도록 축소합니다.
- 필터는 전체 사진에 공통으로 적용됩니다.
- 카메라 직접 촬영과 편집 상태 자동 저장 기능은 포함되어 있지 않습니다.
- 이모지 스티커와 글꼴의 모양은 기기와 브라우저에 따라 달라질 수 있습니다.
- 모바일의 파일 저장 방식은 브라우저 설정에 따라 달라질 수 있습니다.

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| 사진이 열리지 않음 | JPG 또는 PNG 파일로 다시 선택하세요. HEIC 등 일부 형식은 브라우저에서 지원되지 않을 수 있습니다. |
| 다운로드되지 않음 | 사진 네 장을 모두 넣었는지 확인하고 브라우저의 다운로드 차단 여부를 확인하세요. |
| 사진 가장자리가 잘림 | 중앙 기준 자동 자르기가 적용됩니다. 중요한 부분이 중앙에 있는 사진을 선택하세요. |
| 스티커 크기가 바뀌지 않음 | 미리보기에서 해당 스티커를 먼저 선택한 뒤 크기를 조절하세요. |
| 글꼴이나 스티커가 다르게 표시됨 | 기기별 글꼴과 이모지 차이입니다. 최신 Chrome 또는 Edge에서 확인하세요. |
